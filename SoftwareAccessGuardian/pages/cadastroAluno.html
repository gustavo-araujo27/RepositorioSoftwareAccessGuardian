Sobre nós

Conheça melhor o Access Guardian, suas funcionalidades e os recursos utilizados no gerenciamento de acesso.

O que é o Access Guardian

O Access Guardian é um sistema desenvolvido para auxiliar no gerenciamento e na verificação de acesso por meio de cartões RFID.

Qual é a finalidade do sistema

O sistema tem como finalidade facilitar o controle de entrada e saída, permitindo identificar usuários e verificar suas permissões de acesso.

Como funciona a identificação por RFID

O usuário aproxima seu cartão RFID do leitor. O sistema captura o código de identificação do cartão e consulta as informações cadastradas no banco de dados.

Quais tecnologias são utilizadas

O projeto utiliza Electron, JavaScript, banco de dados MariaDB, Arduino, leitor RFID MFRC522 e servo motor para simular o funcionamento de uma catraca.

Quem pode utilizar o Access Guardian

O sistema possui funcionalidades destinadas aos usuários com perfil de segurança e de gestor, respeitando as permissões de cada perfil.

Como o sistema verifica a autorização

Após a leitura do cartão, o sistema verifica se a credencial está cadastrada e autorizada. Em seguida, apresenta o resultado da verificação e controla a abertura ou o bloqueio da catraca.

O que acontece quando o acesso é negado

Quando a credencial não possui autorização, o sistema informa que o acesso foi negado e mantém a catraca bloqueada.
